# Syncify

A cross-platform music discovery app prototype built with Expo, React Native, and TypeScript.

## Run locally

```bash
npm install
npx expo start
```

Use the Expo Go app to scan the QR code, or press `w` for web, `a` for Android, or `i` for iOS (with the required simulators/tooling installed).

## Included in this prototype

- Discover screen with featured mix, mood filters, playlists, and recommended tracks
- Search screen with live song and artist filtering
- Library screen with saved/liked songs
- Radio screen with a featured sample station
- Persistent mini-player UI with play/pause and next-track controls

Playback and catalog entries are currently UI prototypes with sample metadata; licensed streaming integrations and real audio playback are not yet connected.
