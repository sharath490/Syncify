# Syncify

A cross-platform music discovery app prototype built with Expo, React Native, and TypeScript.

## Run locally

```bash
npm install
npx expo start
```

Use the Expo Go app to scan the QR code, or run the app in a browser or simulator with `w`, `a`, or `i`.

## Features in this upgraded prototype

- Discover screen with featured mix, mood chips, playlists, and curated suggestions
- Search and filtering view for songs and artists
- Library screen with liked tracks and saved music
- Radio screen with a featured station UI
- Persistent mini-player with play/pause and next-track controls
- More polished Spotify/Apple Music/YouTube Music-inspired interface

This is still a front-end prototype with sample metadata and design-driven interactions. It does not yet connect to real streaming APIs or licenses.
